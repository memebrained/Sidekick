# SIdekick Privacy Policy

Last updated: October 9, 2026

SIdekick — powered by Señor Inteligente is a browser extension that playfully changes visible standalone instances of “AI” to “SÍ,” displays optional visual effects, and provides an optional token-information panel.

## Information processed locally

After the user opens SIdekick from the Chrome toolbar, the extension receives temporary access to the active webpage and reads visible webpage text only to identify and replace standalone instances of “AI.” This processing happens locally in the browser. SIdekick does not request persistent access to all websites. Page contents are not transmitted to the developer or stored on an external server.

The extension stores the following information locally through `chrome.storage.local`:

- Extension enabled/disabled state
- Visual-effect preferences
- Dark/light appearance preference
- Mascot position
- Local correction counters

This locally stored information is not sold, shared with the developer, or used for advertising or analytics. Users can remove it by uninstalling the extension or clearing the extension’s stored data.

## External market data

When the popup or side panel is opened, SIdekick requests public token-market information from the DexScreener API. The side panel also requests public OHLCV candle data from the GeckoTerminal API. These requests contain the fixed, public Solana token or pool address. SIdekick does not send webpage contents, wallet addresses, browsing history, or locally stored preferences to either provider. Network providers may receive ordinary connection information such as an IP address under their own privacy practices.

Charts are rendered locally with the open-source TradingView Lightweight Charts library. No chart data is requested from or sent to TradingView by the extension.

## External and referral links

SIdekick contains user-initiated links to third-party trading platforms and social profiles. Some trading-platform links are referral links. SIdekick does not open them automatically, modify links on webpages, set referral cookies in the background, or execute trades. A third party receives information only after the user deliberately selects its button, and that service’s own terms and privacy policy then apply.

Referral benefits, eligibility, fees, and availability are controlled by each third-party provider and may change. Users should verify any stated benefit and the destination before creating an account or trading.

## Financial information

SIdekick does not connect to wallets, request seed phrases or private keys, hold funds, execute transactions, or collect financial account information. Market information is informational, may be delayed, and is not financial advice.

## Changes

Material changes to these practices will be disclosed through an updated policy and, where required, through the extension or Chrome Web Store listing.
